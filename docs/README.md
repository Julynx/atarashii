## Features

- Live Markdown to PDF editing.
- Full [markdown-convert syntax](https://github.com/Julynx/markdown_convert/blob/main/CUSTOM_SYNTAX.md) support.
- Autosave, undo / redo, search, zoom in / out, line wrap, logging, printing...
